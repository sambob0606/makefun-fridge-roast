One line for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty: a roast of a smart fridge. The program writes the line to `/output/entry.txt`.

> My smart fridge pushed a firmware update at 2 a.m., rebooted, and forgot how to fridge — the ice maker now identifies as a screensaver.

Why this line: it is specific to smart fridges, not a generic appliance gag — only a smart fridge pushes a 2 a.m. firmware update and reboots. The turn is the ice maker losing its job to a screensaver, which dodges the obvious cracks (ordering groceries, watching you eat) and lands on the one thing a fridge must never forget: keeping things cold.

## Run it

```sh
python3 main.py
```

It writes the single-line roast (no trailing newline) to `/output/entry.txt`, then reads it back and verifies the gate (1–200 characters, one non-blank line) before exiting.
